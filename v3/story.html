RECALLVISION / VERSION 3.0

From video to visual memory.

What if you could ask a video where an object was last seen — and jump straight to the evidence? RecallVision builds a persistent record of scenes, objects and events, then retrieves it to answer questions without processing the full video again.

03 / HOW THE APPLICATION WORKS

One analysis. Reusable memory.

01 · ANALYZERead the video

Sample source frames and generate scene, object and event records using local models.

02 · STOREBuild persistent memory

Save timestamped observations, source references, and verification information in SQLite.

03 · ASKRetrieve an answer

Search stored memory first; inspect specific evidence frames when needed.

04 · REOPENUse it again

Restore analyzed videos and saved answers across application restarts without regenerating memory.

0.32–0.36 s recorded repeated-question retrieval after memory was saved.

First-time CPU memory generation took approximately 202–272 seconds for the three short clips. The website displays archived results; full analysis takes place in the local Streamlit application.
