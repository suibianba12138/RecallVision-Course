# Public demo page

This directory contains a self-contained, text-only summary of recorded course outcomes. It is not an executable C1 artifact replay, does not validate the original fixture, and contains no supporting image/video evidence.

From the repository root:

```bash
python -m http.server 8000
```

Open <http://localhost:8000/public-demo/>.

Suggested order:

1. Explain that C1 is an `EXISTING_ARTIFACT_REPLAY` from the internal course package, not fresh inference.
2. Show the recorded four query results and the stable event reference.
3. Explain that the frame numbers are references only; the corresponding Pixabay-derived JPEGs are not distributed in this public candidate.
4. Show C2 and C2-R as failed independent target-resolution checks (`AMBIGUOUS_TARGET` at P2B), not as positive QA demonstrations.
5. State that long-form performance is `NOT_VALIDATED` and fresh-video end-to-end QA is not established.

This page is a convenience summary, not a substitute for the full internal demo or its evidence artifacts. Do not claim that the asset-restricted public checkout passed a full replay.
