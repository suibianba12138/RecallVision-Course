RECALLVISION 2.0 / LOCAL ENGINEERING PROTOTYPE

From visual observations
to trusted memory.

An evidence-aware, object-centric visual memory application for fixed-camera indoor videos. Analyze objects, review uncertain identities and observations, then ask historical questions with time-linked evidence.

Explore the workflow ↘Watch the recorded C1 demo ↗

Conceptual system overview — not a live hosted inference service.

01 / THE WORKFLOW

Analyze → Explore → Ask.

One local Streamlit workflow connects the video analysis pipeline, persistent identity hypotheses, human evidence review and supported queries.

01 — ANALYZE

Understand the footage

Import a supported local video or reopen a saved analysis. YOLO11n and ByteTrack produce candidate observations and tracked objects. Processing runs locally, not in this static website.

02 — EXPLORE

Build visual memory

Inspect persistent entity candidates, spatial state histories and movement candidates. Confirm or revoke identity relations and review individual observations and events.

03 — ASK

Retrieve with evidence

Use the trusted WHERE, WHEN and BEFORE query path. Supported answers link to source frames and timestamps; ambiguous or missing evidence remains explicit.

02 / THE DESIGN PRINCIPLE

A memory you can question
and correct.

V2 distinguishes automatic detections from accepted evidence. A user can mark an observation as supported, uncertain or missing; review movement candidates; and retract identity or event decisions without altering raw detections.

Video → Detection + tracking → Persistent identity candidates → State and event candidates
↳ Identity & evidence review → Trusted WHERE / WHEN / BEFORE → Timestamped source evidence
Persistent identity

Do not guess continuity

Tracklets can be grouped into candidate entities while preserving ambiguity across occlusions or detection gaps.

Reversible review

Keep decisions auditable

Identity and evidence review is explicit and reversible. A confirmed frame does not certify unseen neighboring frames.

Trusted retrieval

Show uncertainty

Unavailable or insufficient evidence is not silently turned into a confident movement time or object history.

03 / VALIDATION & LIMITATIONS

Engineering progress,
without inflated claims.

416 passed, 7 skipped, 0 failed in the recorded V2 regression suite. The result depended on the existing worktree and external frozen fixtures; fresh-clone reproducibility and final manual browser acceptance were not established.

What is not yet established

Independent real-video evaluation exposed important perception, identity and motion false-positive failures. In the recorded E1 evaluation, 0/5 annotated target objects were resolved automatically. V2 is a constrained engineering prototype, not a validated arbitrary-video understanding model or an automatic person-attribution service.
