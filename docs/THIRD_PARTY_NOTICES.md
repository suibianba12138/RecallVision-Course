# Third-party components and media

This file records components used or declared by the source project. This source-only repository does not bundle third-party package source, wheels, platform binaries, model weights, raw videos, or evidence images. Optional dependencies are not fully pinned, so this is not a resolved SBOM; a complete platform-specific wheel inventory is not a blocker for publishing this source tree. Anyone later redistributing a runtime environment or binary package must review the exact components and their notices.

## Software

- **Ultralytics `8.4.171` (AGPL-3.0):** optional runtime dependency imported by the perception adapter. Its tagged source and ByteTrack implementation are AGPL-3.0; no Ultralytics package source is copied into this repository. Upstream states its AGPL route is intended for projects that publish the entire project under AGPL-3.0, which is why this project's original source is released under AGPL-3.0-only. Its package metadata declares dependencies including NumPy, Matplotlib, OpenCV, Pillow, PyYAML, Requests, PyTorch, TorchVision, psutil, Polars, NVIDIA ML Python bindings, and Ultralytics THOP. See the [tagged source license](https://github.com/ultralytics/ultralytics/blob/v8.4.171/LICENSE), [tagged dependency metadata](https://github.com/ultralytics/ultralytics/blob/v8.4.171/pyproject.toml), and [Ultralytics license guidance](https://www.ultralytics.com/license).
- **ByteTrack:** RecallVision selects Ultralytics' `bytetrack.yaml`; it does not copy standalone ByteTrack source or tracker binaries. The upstream standalone project publishes an [MIT license](https://github.com/FoundationVision/ByteTrack/blob/main/LICENSE). The tracker implementation actually used through Ultralytics is covered by the Ultralytics AGPL terms above.
- **OpenCV:** optional dependency `opencv-python>=4.11`. The [Python wrapper project](https://pypi.org/project/opencv-python/) is MIT-licensed; OpenCV itself is Apache-2.0 for current 4.x releases. Its upstream documentation says wheels include FFmpeg under LGPL-2.1, and non-headless Linux/macOS wheels also include Qt 5 under LGPL-3.0; other bundled components have platform-specific notices. See the package's [third-party license inventory](https://github.com/opencv/opencv-python/blob/4.x/LICENSE-3RD-PARTY.txt). RecallVision does not redistribute these wheels, and the exact installed wheel is not pinned here.
- **Pytest:** optional test dependency `pytest>=7`, MIT; see the [upstream license](https://github.com/pytest-dev/pytest/blob/main/LICENSE).
- **Setuptools:** build requirement `setuptools>=61`; dependency only, not bundled. See [Setuptools licensing](https://github.com/pypa/setuptools/blob/main/LICENSE).
- **PyTorch/TorchVision:** transitive requirements of optional Ultralytics, not direct pinned RecallVision dependencies. They are installed by a user's runtime environment and are not bundled in this source repository.
- **Downloaded model weights:** no weights are bundled. The default identifier `yolo11n.pt` may be downloaded by Ultralytics at runtime; upstream says its trained models are AGPL-3.0 by default. Any separate redistribution of weights requires preserving the applicable upstream terms.
- **Transitive dependencies:** versions/platform wheels resolve at installation time. They are not packaged here, and an exhaustive inventory of unbundled wheels is not required for this source-only release.

The project-owner source statement and frozen-V1 boundary are recorded in [`SOURCE_PROVENANCE.md`](SOURCE_PROVENANCE.md). This license does not grant rights to excluded third-party media or dependency binaries.

## C1 media

The C1 development clip is Pixabay video 82261: <https://pixabay.com/videos/bottle-hands-water-liquid-table-82261/>. The raw clip and all three extracted evidence JPEGs are excluded from the public Git tree. The original local fixture and its images are preserved unchanged for the internal course demo. The public candidate does not claim a full artifact replay without those images. Pixabay's [license summary](https://pixabay.com/service/license-summary/) permits adaptations but prohibits standalone distribution and warns that additional rights may apply; no distribution permission for these particular frames is asserted here.

Visual inspection of the three frames found a bottle and a hand, but no visible face or text identifier. This does not resolve copyright, privacy, or publicity-rights questions.

The independent C2-R Pexels video and the C2 Mixkit video are not included. This notice does not grant rights to any media.
