02 / WHAT OUR COURSE PROJECT BUILT

A complete architecture,
not a new detector.

We combine established perception with an inspectable object-centric memory. The V1 query handlers read stored records instead of processing video pixels at question time.

01 — PERCEPTIONSee

YOLO11n detects bounding boxes; ByteTrack assigns short-term track IDs. Real observations may fragment under occlusion.

02 — MEMORYRemember

P2A associates tracklets into persistent hypotheses. P2B stores observed state segments; P2C/P2D derive evidence-bounded events.

03 — RETRIEVALAnswer

Four typed query handlers retrieve supported states, movement intervals, prior states, or pre-authorized attribution with evidence.
