# RecallVision project website

Source for the RecallVision visual memory project website. Its interactive explorer displays precomputed C1 course artifacts and allows a local original MP4 to be loaded after SHA-256 verification. It does not perform live video inference.

The original course source is in [`main`](https://github.com/suibianba12138/RecallVision-Course). No third-party video or still images are distributed on this site. Code is available under AGPL-3.0-only; see `LICENSE` and `COPYRIGHT`.

The canonical GitHub Pages address for this branch is https://suibianba12138.github.io/RecallVision-Course/ once Pages branch deployment is enabled.
