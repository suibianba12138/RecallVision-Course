02 / What V1 built

A structured memory pipeline.

01 — SEE

Perceive & track

YOLO11n collects frame-level observations. ByteTrack associates detections into short-term trajectories.

02 — REMEMBER

Objects and events

Tracklets become persistent entity hypotheses. State timelines and evidence-bounded movement records preserve observed history.

03 — ANSWER

Retrieve evidence

Typed queries retrieve prior observations, an event interval, or an authorized attribution record without repeating perception.
